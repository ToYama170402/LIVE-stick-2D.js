# LIVE-stick-2D.js

本家：<https://github.com/ToYama170402/LIVE-stick-2D>

骨格推定をブラウザで動かして棒人間イラストを動かす。

## 概要

これは、ブラウザ上で骨格推定を行い、棒人間のイラストを動かすアプリケーションです。ユーザーは自分のウェブカメラを使用して、リアルタイムで骨格データを取得し、それに基づいて棒人間のアニメーションを制御できます。

## 主な機能

- ウェブカメラからのリアルタイム骨格推定
- 棒人間イラストのアニメーション制御

## 使用技術

- JavaScript
- HTML5
- CSS3
- MediaPipe（骨格推定ライブラリ）

## 使用方法

<https://github.com/ToYama170402/LIVE-stick-2D>にアクセスするだけです。

### クエリパラメーター

以下のクエリパラメーターを使用することで、アプリケーションの動作をカスタマイズできます。

- `?lineWidth=8` : 棒人間の線の太さを指定します（デフォルトは8）。
- `?numPoses=1` : 同時に検出するポーズの数を指定します（デフォルトは1）。

例: `https://toyama170402.github.io/LIVE-stick-2D/?lineWidth=10&numPoses=2`
